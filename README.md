# Kamalesh Ayyala — Portfolio Website (React + Vite)

A responsive, single-page portfolio built with React, Vite, and preserved original styling/behavior.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview the production build:
   ```bash
   npm run preview
   ```

## Migration Notes

- All original HTML structure, text, links, and project illustrations have been preserved.
- CSS from the original `style.css` has been migrated to `src/index.css` with no design changes.
- Mobile navigation and scroll reveal animations reimplemented with React hooks.
- Assets are stored in `public/assets/` and referenced as `assets/...`.

## Deployment

You can deploy the `dist/` folder to GitHub Pages, Netlify, or Vercel as a static site.
